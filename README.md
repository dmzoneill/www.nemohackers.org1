# nemohackers.org (version 1)

Version 1 of the nemo hackers community site.

## Contents

Server-side include (`.shtml`) pages on security topics, tools and texts, Perl
CGI scripts for news, uploads and top lists, an Ultimate Bulletin Board forum
and a Java IRC client.

## Tech

- HTML with server-side includes
- Perl CGI and some PHP

This is an archive of an old site, kept for reference.
